# Personal page

This is my personal landing page, project portfolio and personal and technical blog.

## My decision tree for type of blog content

- Technical: "Here’s how to do this reliably."
- Essay: "Here’s what I think, and why."
- Analysis: "Here’s a question, method, evidence, and result."
- Note: "I tried or noticed this; here’s what happened, in this context."

Notes can contain code and be substantial.
The key is their scope and ambition: one focused point, often provisional or specific to your setup.
It’s not a label for unfinished writing.
